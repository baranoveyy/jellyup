# JellyUp invite page

Opens a friend's challenge or group invite in the JellyUp game (`jellyup://c/<code>`). The code rides in the URL fragment, so it is never sent to this host. Source: `Web/jellyup/index.html` in the game's repository.

`privacy/` is the game's privacy policy (https://baranoveyy.github.io/jellyup/privacy). Source: `Web/jellyup/privacy/index.html`, text `StoreListing/PrivacyPolicy.md`.
